# René le Bak

Een drankspel-app op de muziek van René le Blanc. Leg de telefoon in het midden, tik voor het volgende nummer, en laat het scherm bepalen of je moet drinken.

## Spelregels

1. Leg de telefoon in het midden en ga er met je vrienden omheen staan of zitten.
2. Druk op **start**, en om de beurt drukt iemand op het scherm.
3. Wordt het scherm **rood**? → geen bak.
4. Wordt het scherm **groen** en hoor je **If I Tell You**? → 1 bak.
5. Wordt het scherm **groen** en hoor je de **hardstyle variant**? → 2 bakken.
